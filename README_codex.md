# Glamping data and code

Data and analysis code for **Glamping as a Ritual Experience: Exploring Emotional Value in Outdoor Recreation through Visual and Textual Analysis**.

Authors: Shihan (David) Ma, Qin Li, and Shun Ye (Zhejiang University).

Download the complete package from [Release v1.0](https://github.com/liqunqun07/glamping-data-code_codex/releases/tag/v1.0). Extract the ZIP and follow the included README.md for requirements, data descriptions, and execution instructions.

The package contains the data, retained model artifacts, analysis scripts, and output files. The platform username column has been removed from raw_reviews.csv; all other source data values are unchanged.
