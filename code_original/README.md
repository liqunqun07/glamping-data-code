# Historical method records

These selected files document upstream procedures used before the current analysis package. They are not called by `main.py` and are not required for its downstream run.

- `04rerundistance.py` shows the word-vector and Word Mover's Distance calculation route. Its archived input path and the external Google News vectors are not supplied here; the preserved 719 by 719 matrix in `../retained/` is the input to the current Ward clustering stage.
- `05_lda_topic_model.py` records text preparation and LDA model exploration. It expects the earlier translated-text preparation and modeling environment. The nine-topic selection and alpha 0.91 setting involved interpretation, so a fresh fit is not guaranteed to match the preserved assignments or visualization.
- `lda_custom_stopwords.csv` records the historical preprocessing word list and is not read by the current pipeline.

The current analysis uses the fixed historical WMD matrix and LDA assignments in `../retained/`; fitted clustering, factors, tables, image validation, and figures are generated by `main.py`.
